# 心情签名与空间 · mood-qzone

这是独立运行的定时插件，安装在 QQ Agent 加载器实际扫描的 `plugins/mood-qzone/`。安装版对应 `resources/app/plugins/mood-qzone/`，不是 exe 旁边的同名目录。

在控制台「插件 → 心情签名与空间 → 设置」配置后保存即可，约 2 秒内调度读取新值，无需重启。生成中的任务在发布前重新核对设置；如果设置变化，放弃旧内容。已经提交给 QQ 的请求无法撤回。

空间说说和每晚日记引用主人记忆时，统一用“他”描述主人，机器人自己的感受仍用“我”。主人原话中的“我”不会被当成机器人的亲身经历；其他人物按原上下文区分，资料不足时不强行提及主人。

## 配图修复（v1.1.3）

- 主图源改用 Bing 图片专用接口，读取完整结果后下载 Bing 自己的缩略图。不再依赖宿主只读取前 50 KB 的通用图片页面解析器。
- 优先使用模型给出的简短英文检索词，并检查结果标题与关键词是否相关，丢弃无关推荐图。英文空格使用 `%20` 编码。
- Bing 搜索与缩略图优先直连，失败时再用系统代理；Wikimedia 保留为备用。代理开关或海外图源连接故障不会让全部取图路径都失效。
- 宿主下载等待超过 4 秒后切换系统网络，整个取图阶段最多等待 75 秒。`image-diagnostic.json` 保存最近检索词、使用图源、下载字节数及各次失败原因。
- 错误保留 curl 的退出码和 stderr 摘要，避免长命令把真正的超时原因挤掉。

### v1.1.2 的备用通道

- 通用图片搜索不可用时，使用 Wikimedia Commons 的结构化搜索与图片元数据。
- 备用网络先尝试宿主安全下载，再尝试 Windows 系统网络，最后尝试已配置的 HTTP 代理。没有开启系统代理也能使用 Windows 通道。
- 支持 Commons 当前返回的 `thumb.wikimedia.org` 缩略图，以及 `upload.wikimedia.org` 原图。备用通道仅限固定 Wikimedia HTTPS 主机，逐跳检查重定向，仍受全局浏览锁定约束。
- AI 为配图提供简短的英文视觉关键词；手填中文配图词仍优先用于通用搜索，并由 AI 翻译供 Commons 使用。英文无结果时再尝试原词。
- 两条取图通道都校验图片字节类型与 5 MB 大小上限，失败时继续尝试候选图。停用或取消会终止备用网络请求。

## 用户白名单（v1.3.0）

在插件设置的「用户白名单（QQ 号）」填入允许的 QQ 号，用逗号、空格或换行分隔。默认留空：禁止聊天主动触发，定时任务继续按设置运行但不读取任何用户记忆。

- 谁主动触发就只读取谁的聊天记录和成员长期印象；定时任务只读取全部白名单用户的记忆。
- 以宿主会话里的真实发送者 QQ 号校验身份，不接受模型参数、昵称、群号或引用正文中的 QQ 号作为身份。多人混合批次无法确认唯一发起人时拒绝，请由白名单用户单独发送请求。
- 写作要求直接取发起人本次消息原文，避免模型把其他人的记忆夹入工具参数。
- 排除机器人回复、未知作者、未绑定 QQ 号的旧印象及白名单外成员。用户自己的话若提到他人，仍属于该用户的发言；不会额外读取被提及者的记忆。
- 历史生成文案和心情按白名单及参考用户隔离。更新前的历史、其他人的历史、白名单变化前的历史不再送入模型；原发布次数和记录保留。
- 生成期间白名单变化时取消旧任务，发布前再次校验权限。

## 聊天触发

白名单用户在机器人能回应的私聊或群聊里直接说，群聊可先 @机器人：

- “按现在的心情换个签名。”
- “发一条关于星空的空间说说，写得轻松一点。”
- “你现在心情怎么样？今天发了几条说说，下次什么时候发？”

对应工具为 `mood-qzone__update_signature`、`mood-qzone__publish_post`、`mood-qzone__status`。前两个立即生成并执行，不受每日次数、最小间隔、允许时段和失败冷却限制，每日次数设为 0 时也可以聊天触发。聊天动作单独统计，不占定时任务配额、不影响定时任务间隔；定时任务继续遵守原限制。配图、可见范围、只预览、插件总开关与任务互斥仍生效。用户本次话题仅用于这次写作，不会修改长期配置。动作记录里的 `trigger: chat / timer` 区分来源。

普通闲聊和状态查询不会要求模型发布。插件已停用或聊天本身未触发机器人响应时，聊天工具不执行。

## 定时任务设置

### 每晚日记（v1.4.0）

在设置中开启「每天 22:00 写今日日记发到 QQ 空间」，即可每天 UTC+8（北京时间/新加坡时间）22:00 开始生成当天日记，完成后以空间说说发布。新安装默认关闭，本机更新可按用户请求开启。

- 日记独立于普通签名/说说的次数、间隔和运行时段，每天最多真实发布一篇；普通说说次数为 0 也不阻止日记。多个任务到点时优先处理日记，已有任务则完成后再检查。
- 只参考当天零点到开始生成时白名单用户的聊天，不使用旧长期印象或昨日内容作为当天经历，不联网找话题补充经历。当天聊天较少时写简短真实的当下感想，避免编造现实活动。归档仍按每会话最多 50 条、汇总最近 60 条及文本长度上限提供素材。
- 沿用机器人全局人设、自称、额外写作要求、配图、可见范围和「只生成预览」设置。日记最长 800 字，开头标明当天日期。预览和真实发布单独计数。
- 保留发布记录，反复检查、重启、关闭再开不会重复发布。22 点后恢复运行可在当晚补发，不补前一天；生成跨午夜则取消旧日记。
- 生成失败尚未调用 QQ 时半小时后重试，限当晚。QQ 已调用但结果未确认时不自动重发。关闭日记开关或插件总开关、生成中更改设置均会在提交前取消旧任务。
- 状态工具返回 `diaryEnabled`、`diaryUsed` 和 `nextDiaryAt`；动作记录的 `kind: diary` 区分普通说说，`trigger: timer` 表示定时来源。

### 普通签名和说说

- 默认每天最多修改签名 3 次、发表说说 1 条，运行时段 09:00–22:00，不配图。
- 签名间隔 180 分钟，说说间隔 360 分钟，任意两个动作间隔 10 分钟。
- 每天次数是上限，按允许时段的中点等距安排。间隔过长、停机或网络故障可能少发；不会为凑数突破时段、配额或间隔。
- 所有时间、每日配额归属均按 UTC+8（北京时间/新加坡时间）。时段支持跨午夜；结束时刻不发送。次数填 0 可分别关闭定时签名和定时说说，聊天触发不受影响。
- 自称留空时跟随全局机器人名字；性格读取全局人设，仅参考白名单用户最近聊天和长期印象。不修改原聊天、已读标记或记忆文件。
- 联网沿用主程序的搜索配置。搜索关闭、失败或全局浏览锁定开启时，仍能根据记忆写心情；不会把没有搜索到的内容写成已知新闻。
- 本机网络使用虚拟 IP 时，宿主安全图片下载可能失败。插件会通过 Windows 系统网络或已启用的 HTTP 代理取图。备用通道仅限固定的 Bing 搜索、Bing 缩略图和 Wikimedia HTTPS 主机，逐跳检查重定向并限制下载大小。全局浏览锁定开启时禁用备用传输通道。Commons 图的作者、许可、说明页、图源与实际检索词会写入预览文件。
- 配图有「不配图」「尽量配图」「必须配图」三种。后两者会搜索一张图，经安全下载层或固定图源的系统网络通道读取图片字节，再交给 SnowLuma 上传。最多 5 MB，支持 JPEG/PNG/GIF/WebP。找不到图时，尽量模式降级为文字，必须模式延后 30 分钟再试。
- 「只生成预览，不修改 QQ」按计划写预览文件，不调用 QQ 写接口；预览与真实发布分别计数。

## 状态与排障

数据目录使用宿主 `QQ_AGENT_DATA_DIR`，安装版通常为 `D:\QQAgent\QQ Agent\data\mood-qzone\`。

| 文件 | 内容 |
| --- | --- |
| `config-snapshot.json` | 最近生效的本插件配置及保存时间（不复制主程序 API Key） |
| `state.json` | 当前状态、最近错误、下次计划、32 天动作记录、次数和跨天冷却依据 |
| `preview.json` | 最近一次已生成文案、心情、搜索结果、配图来源和降级原因（不保存图片 base64） |
| `image-diagnostic.json` | 最近取图是否成功、检索词、图源、字节数和失败原因 |

主配置仍由宿主的 `data/config.json` 中 `skills.mood-qzone` 管理，快照不是第二套配置。

发布前先将次数预占记录落盘，然后调用 QQ。如果请求超时或进程在途退出，记录为 `uncertain`，保留这次次数和间隔，不自动重发原文，以免一条说说发两遍。生成或配图阶段失败尚未触碰 QQ，不占发布次数；定时任务 30 分钟后再试，聊天触发不受此冷却限制。

坏配置会显示在 `state.json.lastError`，修正设置后自动恢复。状态文件损坏时拒绝把配额清零，加载错误会出现在插件页和主程序日志中。

插件关闭和热重载会清理定时器并中止 AI 生成；共享互斥防止新旧实例重复提交。`mood.status` 提供只读运行状态；聊天写入工具与定时器共用同一条生成、校验和发布流程。

## 本机兼容依据

本安装包未包含 `doc/extend_development/*.md`；开发目录已备有四份扩展文档。修复同时对照本机 QQ Agent 0.4.0 的 `src/plugin-loader.js`、`src/skills/manifest.js`、`src/skills/manager.js`、`src/routes.js`、`src/llm.js`、`src/web-search.js` 与 SnowLuma `config-CEQwQxHY.js` 实际代码：

- 签名：`set_self_longnick({longNick: string})`。
- 说说：`send_qzone_msg({content, images?: ["base64://…"], ugc_right})`，成功要求返回 `tid`。
- 配置：清单的 `settings` 与 `configSchema`，通过 `api.config()` 动态读取。
- 生命周期：`setup / activate / deactivate / dispose`。
- 文件热重载：宿主 watcher 自动扫描，入口查询串传递给 engine 模块以免依赖缓存。

运行独立测试：在开发目录执行 `node --test test-mood-qzone.mjs test/mood-images.test.mjs`。测试用注入的 AI/QQ 接口和临时目录，不向真实 QQ 发布测试内容。


## v1.2.0 梗鲸配图

默认来源为「自动」：从 https://aigengtu.com/gallery-index.json 读取图库，用标题和故事匹配正文与情绪，再让模型从候选编号中选图；不合适则尝试 Bing / Wikimedia。也可选「梗鲸表情包」或「网络图片」。无需填写 Key 或图源地址。「不配图」设置仍然生效。

只下载索引中 img.aigengtu.com/meme/ 的原图，校验响应类型、文件魔数和 5 MB 上限，拒绝 HTML 假图；发送的是已校验字节的 base64，不让 QQ 再拉远程地址。坏图自动换候选。索引上限 4 MB，缓存一小时。

按聊天标识持久记录原图 URL 与 SHA-256，同一聊天不会重复；定时任务独立记录。发送前预占，结果不确定也不重试同一张；只预览不占用。记录不会随 32 天动作历史清理。网络自动读取系统代理或 HTTP(S)_PROXY，并可直连回退，无需部署机器填写 Clash 端口。

空间发布直接调用 mood-qzone__publish_post，不需要提前调用内置 search_images。
