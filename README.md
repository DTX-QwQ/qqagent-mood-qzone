# QQ Agent 心情签名与空间插件

`mood-qzone` · v1.4.0

根据机器人性格、近期聊天记忆和心情，定时更新 QQ 个性签名、发表 QQ 空间说说，也可以通过聊天立即触发。

## 功能

- 独立定时器，支持每日次数上限、最小间隔、运行时段与跨天计数。
- 晚间日记独立开关：每天 UTC+8 的 22:00 开始写当天日记，完成后发布到 QQ 空间。每天最多一篇，重启和开关切换不重复发布。
- 用户白名单：仅白名单用户能主动触发；谁触发只用谁的聊天和长期记忆，定时只参考白名单。默认留空，禁止聊天主动触发，定时不读取用户记忆。
- 白名单用户聊天要求“换个签名”或“发一条说说”即可立即生成；聊天触发与定时配额分别统计。
- 可选联网话题、说说配图、可见范围和只生成预览。
- 配图支持自动、梗鲸表情包和网络图片；根据正文与情绪选图，按会话持久去重。
- 配置动态生效；生成中配置变更会取消旧内容。
- 发布前持久化预占记录，超时保留未确认状态，避免自动重复发布。

## 安装

1. 下载本仓库，将 `plugins/mood-qzone` 整个文件夹复制到 QQ Agent 实际加载的插件目录。
2. 源码运行版通常使用 `<QQ Agent 根目录>/plugins/mood-qzone/`；本次验证的 Windows 安装版使用 `<安装目录>/resources/app/plugins/mood-qzone/`。
3. 在 QQ Agent 的「插件」页找到「心情签名与空间」，进入设置并保存。启用文件热重载时会自动加载。

这是 QQ Agent 的宿主插件，不能作为独立 Node.js 程序启动。它依赖宿主的配置、模型调用、OneBot/SnowLuma、搜索与安全下载模块；代理备用通道还使用宿主提供的 `undici`。

当前代码依据本机 QQ Agent 0.4.0 的实现验证，其他版本的内部接口兼容性尚未验证。安装位置必须保证入口中的 `../../src/` 指向宿主源码目录。

默认每天最多更新 3 次签名、发表 1 条说说，运行时段为 UTC+8 的 09:00–22:00，不配图。插件启用后会按设置执行真实 QQ 操作；如需先检查内容，可开启「只生成预览，不修改 QQ」。

## 使用示例

- 按现在的心情换个签名。
- 发一条关于星空的空间说说，写得轻松一点。
- 你现在心情怎么样？今天发了几条说说，下次什么时候发？

详细配置、数据文件与故障行为见 [插件说明](plugins/mood-qzone/README.md)。运行数据由宿主保存在自己的数据目录，本仓库不包含主程序配置、密钥、聊天记录或预览内容。生成时会通过宿主模型服务处理人设和选取的记忆。

## 测试

使用支持 `AbortSignal.any` 的现代 Node.js（建议 Node.js 22 或更新版本）：

```sh
npm test
```

测试使用临时目录和注入的 AI/QQ 接口，不调用真实 QQ 发布接口。覆盖晚间日记的 22 点边界、当天资料范围、独立配额、开关、重启去重、跨午夜取消、失败重试及预览，以及原有白名单、记忆隔离、聊天触发、配额和图片安全功能。测试通过不代表已验证所有 QQ Agent / SnowLuma 版本或真实账号发布行为。
